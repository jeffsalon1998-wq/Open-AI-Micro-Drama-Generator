# Retention Checklist — use before posting every episode

## The 3-second test
- [ ] First frame is mid-action (slap, kneel, death, rejection) — not a wide shot
- [ ] First spoken line is shocking and under 12 words
- [ ] On-screen text states the hook (scroller reads it in 1 second)

## The loop test
- [ ] One clear question posed in first 10 seconds
- [ ] That question is NOT answered this episode
- [ ] It connects to the series loop question

## The escalation test
- [ ] New information / twist / danger every ~5 seconds
- [ ] Stakes rise beat by beat (never flat, never filler)
- [ ] Villain is hateable within 5 seconds

## The payoff test
- [ ] One small loop closed (satisfaction — revenge, reveal, rescue)
- [ ] One bigger loop opened before the end

## The cliffhanger test
- [ ] Final 3 seconds = reveal, question, or danger
- [ ] Last line forces "Next Episode" tap
- [ ] No resolution, no "the end", no slow fade

## The dialogue test
- [ ] Every line reveals, threatens, or shocks
- [ ] No exposition dumps, no small talk
- [ ] At least one quotable line (caption / thumbnail material)

## If any box is unchecked → fix it before generating video.
## Hooked Series Mode in the generator enforces all of the above automatically.
